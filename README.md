# The Silk Road

This site is a class project built around student research on the Silk Road. It brings together object pages, thematic essays, and a map-based view of places and materials connected through historical exchange.

The project is written primarily in Markdown and published as a static website with Jekyll and GitHub Pages. Page content lives in folders such as `objects/` and `essays/`, while shared layouts, includes, and styles turn that content into a browsable collection.

## Teaching Goals

This kind of project asks students to think beyond the traditional paper. Writing for the web requires attention to structure, images, metadata, links, navigation, citation, and audience. Those choices build practical digital literacy while also asking students to consider how historical arguments change when they are presented as collections, maps, and connected objects rather than as linear essays alone.

## Site Structure

- `objects/`: student object pages with images, metadata, and short interpretive essays
- `essays/`: thematic student essays that connect multiple objects or historical patterns
- `assets/`: CSS, images, and other site assets
- `_includes/`: reusable page components
- `_layouts/`: Jekyll layout templates
- `_data/`: structured data used by navigation and shared components
- `docs/`: optional Xanthan documentation and examples retained for reference

## Framework

The site uses the Xanthan web framework, a Jekyll-based framework for digital scholarship, teaching projects, and visual essays.
